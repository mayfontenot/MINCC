# MINCC
## Summary
Open-source, cross-platform compatible JavaFX application that uses Java Cryptography Architecture to deliver end-to-end encrypted, peer-to-peer chats without a centralized server's prying eyes.

## Name Origin
Intended to be pronounced mink, it is a recursive acronym for MINCC Is Not a Centralized Chat, M was arbitrarily chosen because it is the first letter of the author's name.

## Intentions
MINCC is intended to be work without a centralized server, such as Google, who may have three-way encryption methods to spy on users. In the future, MINCC will have implementation to work across various communication mediums. MINCC works a lot like the contact and messages app in a phone, with the addition of cryptographic features. MINCC uses asymmetric cryptography to create public and private key-pairs used for encrypted two-way communication. MINCC is open-source and cross-platform compatible.
